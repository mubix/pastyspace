If it’s on your clipboard, it belongs here.

Paste text or code. Drop a screenshot straight from your clipboard. Drag files onto the page, or use the file picker.

Once saved,

The app rejects edits and overwrites after saving. Whoever opens the link sees the same saved paste. Need a revision? Make a new paste.

Pipe text from a command, send a file with curl, or claim a URL directly. Read plain text back from /raw/your-name.

Small enough

A Flask app, a SQLite database, and locally bundled browser libraries. Run the included Docker Compose setup on a machine you control.

Simple has
its boundaries.

PastySpace is a small sharing tool. Here’s what to expect before you give it a home.

  • No accounts or built-in access control.Anyone who can reach a paste or attachment URL can read it. Add access control at your reverse proxy if you need a private instance.
  • Write once doesn’t mean forever.There’s no automatic expiry, but the server owner controls the database. Keep a separate copy of anything you need to preserve.
  • 50 MB per request, by default.Text, attachments, and upload overhead share that limit. The server owner can change it.
  • A pastebin, not a secret vault.There are no paste passwords or end-to-end encryption. Use it for content you’re comfortable sharing with people who can reach the server.
